# IITM Feedback Form (Demo Project)

A simple student feedback form created as a personal learning project to practice building a frontend application and connecting it to a real backend using Supabase.

I built this project while learning:

- HTML & CSS for creating the UI
- JavaScript for form handling and validation
- Supabase for backend and database integration
- Row Level Security (RLS) for controlling database access

The goal was to understand how a simple frontend form can communicate with a real database instead of relying only on browser-side storage.
## Tech Stack

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages
